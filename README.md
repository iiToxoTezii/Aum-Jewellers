# Aum Jewellers

A luxury, ultra-premium jewelry store website featuring high-end bespoke collections, corporate gifting, and stunning AI-generated macro photography.

## 💎 Features
- **Signature Collections:** Dedicated grids for Gold, Diamond, Bridal, and Modern Silver pieces.
- **Precious Stones Gallery:** A seamless masonry layout showcasing exquisite gemstones like Ruby, Sapphire, and Emerald.
- **Corporate Giftables:** Meticulously embossed custom silver and gold coins for elite clientele.
- **Responsive & Seamless:** Buttery smooth animations, custom easing, scroll-padding, and full mobile responsiveness.
- **Interactive Experience:** Smooth anchor scrolling, tactile button feedback, and Google Reviews integration.

## 🚀 How to Publish on GitHub Pages (No Code Required)

Since you want to host this site directly via GitHub for free, follow these simple steps to publish your live website!

### Step 1: Create a GitHub Repository
1. Go to [GitHub.com](https://github.com/) and log in (or create an account).
2. Click the **"+" icon** in the top right corner and select **New repository**.
3. Name your repository (e.g., `aum-jewellers-website`).
4. Keep it **Public**.
5. Click **Create repository**.

### Step 2: Upload Your Website Files
1. On your new repository page, click the link that says **"uploading an existing file"**.
2. Open your computer's file explorer and find your `c:\Aum Jewellers` folder.
3. Drag and drop **all the files and folders** from inside `Aum Jewellers` (especially `index.html`, `style.css`, `script.js`, and the `images` folder) into the GitHub window.
4. Once they finish uploading, click the green **Commit changes** button.

### Step 3: Turn on GitHub Pages
1. In your repository, click the **Settings** tab (the gear icon near the top right).
2. On the left sidebar, click **Pages**.
3. Under the "Build and deployment" section, find the **Source** dropdown and make sure it says "Deploy from a branch".
4. Under the **Branch** dropdown, select `main` (or `master`), keep the folder as `/ (root)`, and click **Save**.

### 🎉 You're Live!
GitHub will now build your site. Give it 1-2 minutes, refresh the page, and you will see a banner at the top providing you with your live URL (e.g., `https://yourusername.github.io/aum-jewellers-website/`). 

You can now share this link with anyone!
